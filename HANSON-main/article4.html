Технологии и фреймворки

10.09.26

Ruby on Rails (Rails) — веб-фреймворк с открытым исходным кодом, созданный Дэвидом Ханссоном в 2004 году. Включает всё необходимое для создания веб-приложений, работающих с базами данных, по архитектурному шаблону MVC . MVC (Model-View-Controller) — архитектурный шаблон, разделяющий приложение на три слоя: модель (работа с данными), представление (отображение) и контроллер (обработка запросов). Лежит в основе Rails . Ruby — высокоуровневый динамический язык программирования, на котором написан Rails. Создан Юкихиро Мацумото (Matz) . Active Record — часть Rails, отвечающая за взаимодействие с базой данных. Позволяет представлять строки таблиц как объекты и работать с ними без написания SQL-запросов . Action Pack — набор библиотек Rails, включающий Action Controller (обработка запросов) и Action View (генерация ответов) . ERB (Embedded Ruby) — формат шаблонов, представляющий собой HTML-файлы со встроенным кодом Ruby. Используется для создания представлений в Rails . Gem (гем) — пакет переиспользуемого кода для Ruby. Гемы расширяют функциональность Rails-приложений .

Принципы разработки

«Конвенция важнее конфигурации» (Convention Over Configuration, CoC) — ключевой принцип Rails: фреймворк предлагает разумные соглашения по умолчанию, избавляя разработчика от необходимости писать конфигурационные файлы для каждого элемента . DRY (Don't Repeat Yourself — «Не повторяйся») — принцип разработки, согласно которому каждая часть логики должна иметь единственное представление в коде. Один из столпов философии Rails . Scaffolding — автоматическая генерация базового кода (моделей, контроллеров, представлений) на основе соглашений Rails

Продукты и проекты

Basecamp — система управления проектами, запущенная в 2004 году. Первое приложение, построенное на Rails . HEY — сервис электронной почты от 37signals, запущенный в 2020 году как альтернатива Gmail и Outlook . ONCE — модель распространения программного обеспечения от 37signals: единоразовая покупка вместо подписки. Первый продукт — Campfire . Omarchy — Linux-дистрибутив на базе Arch Linux, созданный Ханссоном. Позиционируется как «Agent-нативная» операционная система . Hotwire — набор инструментов для создания современных веб-приложений без написания большого объёма JavaScript . Kamal — инструмент для развёртывания веб-приложений, упрощающий деплой .

Список терминов
Convention over Configuration (Соглашения по конфигурации)
Принцип, согласно которому фреймворк использует разумные настройки по умолчанию. Разработчику нужно что-то конфигурировать только в нестандартных случаях, что сильно сокращает количество кода
«Workaholism — это не героизм»
Убеждение, что работа сверхурочно — это не решение проблем, а скорее маскировка неэффективности. «Трудоголики упускают суть»
«Планирование — это догадки» (Planning is guessing)
Идея о том, что долгосрочные бизнес-планы в быстро меняющемся мире почти бесполезны
